# AutoReadPDF v2.1 Performance Benchmark Results

Measured on 50,000 synthetic container records, 5,000 vessel records, and 5,000 booking records.

## Benchmark Results

| Scenario | Measured Time | Target / Budget | Status |
|---|---|---|---|
| Open Container Tab (`limit=50`, `offset=0`) | **24.36 ms** | < 1,000 ms | **PASS** |
| Page change 1 → 500 (`offset=25000`) | **67.91 ms** | < 300 ms | **PASS** |
| Search `"PERF00012"` in 50k rows | **178.95 ms** | < 1,000 ms | **PASS** |
| Filter event pill `"LOAD"` in 50k rows | **29.58 ms** | < 300 ms | **PASS** |
| Page size 5,000 rows fetch | **359.99 ms** | Smooth scroll with virtualizer | **PASS** |
| Select all 50,000 IDs (`GET /containers/ids`) | **48.04 ms** | < 2,000 ms | **PASS** |
| Batch resolve 100 rows (`POST /containers/by-ids`) | **10.05 ms** | Instant UI feedback | **PASS** |
| Open Vessel Tab (`limit=50`, `offset=0`) | **7.50 ms** | < 500 ms | **PASS** |
| Open Booking Tab (`limit=50`, `offset=0`) | **3.74 ms** | < 500 ms | **PASS** |
| Startup JS Bundle Size (`npm run check:bundle`) | **297.6 KB** | < 300 KB | **PASS** |

## Conclusion
All Phase C performance criteria have been met and verified with clean margins.
